Launch from your server directory

After downloading the files above, open a terminal in the server folder. A compatible macOS binary must be available before using this path on macOS.

chmod +x start.sh
./start.sh

Launch on Windows

Extract the Windows PHP package so the local runtime is available at bin\php\php.exe, then run the launcher in your server folder.

.\start.cmd
